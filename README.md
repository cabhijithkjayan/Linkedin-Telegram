# Telegram Jobs -> LinkedIn

Posts new job messages from a Telegram channel to LinkedIn in a fixed template.
Runs on GitHub Actions at 9:00 AM and 2:00 PM IST. No AI, no images.

Secrets: `TBOT_KEY`, `LINKEDIN_ACCESS_TOKEN`
Files: `telegram_jobs.py`, `requirements.txt`, `.github/workflows/telegram_jobs.yml`, `telegram_jobs_state.json` (auto-created)
